# AI-enabled scientific discoveries research pack

This dated pack is an audited starting point for expanding AIMathBase beyond mathematics.

- `discoveries.csv` — 25 included, source-backed cases with AI role, human role, evidence stage, tier, result, and caveat.
- `exclusions.csv` — adjacent, rediscovered, contested, prediction-only, and capability-only claims that should not inflate a strict discovery count.
- `coverage_ledger.csv` — what this sweep covered and where research remains incomplete.
- `METHODOLOGY.md` — definitions, inclusion rules, tiers, limitations, and expansion requirements.
- `artifact.json` — canonical report data and presentation manifest.
- `report.html` — self-contained reader generated and validated from `artifact.json`.
- `VALIDATION.md` — reproducible checks and handoff limits.

The pack is explicitly **not exhaustive**. It is designed to be extended without converting predictions into facts or erasing human scientific work.
